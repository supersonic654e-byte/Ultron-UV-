# Documentation Index

Public documentation for the Ultron UV research platform. All documents in this folder are written to be **public-safe**: no credentials, real network endpoints, facility maps, or restricted calibration values.

> [!IMPORTANT]
> Ultron UV is a **research prototype**. It is not a certified medical device and has not completed clinical efficacy validation. See [Safety and Limitations](SAFETY_AND_LIMITATIONS.md).
